📊 Retail Business Intelligence Analysis

Project Overview

The Business Intelligence Analysis is an interactive business intelligence project developed using Microsoft Power BI to evaluate retail operations and uncover insights into sales performance, profitability, customer behaviour, product categories, regional performance, and product returns. The project transforms retail transactional data into meaningful visual insights, enabling stakeholders to monitor key performance indicators, identify business trends, evaluate profitability, and make informed, data-driven decisions.

🎯 Project Objectives

The primary objective of this project was to develop an interactive dashboard that provides a comprehensive view of retail business performance.

The analysis focuses on:

- Evaluating overall revenue, costs, and profitability.
- Identifying high-performing and low-performing product categories.
- Analysing revenue performance across different regions.
- Monitoring monthly revenue trends and changes in business performance.
- Understanding customer distribution and purchasing behaviour.
- Evaluating average order value and revenue per customer.
- Analysing product returns and return trends across regions.
- Identifying opportunities to improve revenue generation and operational efficiency.

🛠️ Tools and Technologies

- Microsoft Power BI: Dashboard development and data visualisation.
- Power Query: Data cleaning, transformation, and preparation.
- DAX (Data Analysis Expressions): Creation of calculated measures and business KPIs.
- Data Modelling: Establishing relationships between fact and dimension tables.

📌 Dashboard Structure

The dashboard is organised into three interactive analytical pages.

1. Retail Performance Overview

Provides a high-level summary of the business's financial and operational performance.

Key metrics and visualisations include:

- Total Revenue
- Total Cost
- Total Profit
- Average Order Value
- Revenue and Profit by Product Category
- Monthly Revenue Trend
- Revenue by Region

2. Performance Analysis

Provides a deeper examination of retail performance, helping identify trends, compare business segments, and evaluate factors influencing revenue and profitability.

The analysis focuses on product and category performance, regional contributions, and changes in business performance over time.

3. Customers and Returns Analysis

Examines customer distribution and product return performance.

Key metrics and visualisations include:

- Unique Customers
- Total Return Amount
- Return Rate
- Revenue per customer 
- Customer Distribution by Gender
- Monthly Return Amount Trend
- Return Amount by Return Reason

The dashboard demonstrates how business intelligence tools can support retail decision-making by:

- Highlighting revenue and profitability performance.
